# PixelNorte

Sitio Web institucional de PixelNorte, desarrollado para el TP3	Integrador de Laboratorio Full Stack.

## Estructura del Proyecto
- `index.html`: Página de Inicio y Quienes Somos.
- `servicios.html`: Lista de Servicios y Precios.
- `contacto.html`: Formulario de Contacto.
- `style.css`: Estilos de Sitio (Flexbox, Grid y Mobile First).
